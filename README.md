## 🚀 Key Features

1. **5-Step Event Planning Wizard**
   - Streamlined 5-step interactive wizard (Event & Date preference, Guests & Location, Services & Decor Requirements, Contact details, Review).
   - Instant WhatsApp dispatch: Formatted enquiry text is compiled directly into a contextual WhatsApp chat with Ram.

2. **Authentic Telugu Quotes & Dialogues Hub**
   - Popular Telugu movie dialogues (written in English script) capturing the festive essence of Telugu weddings and celebrations (*Shatamanam Bhavati*, *SVSC*, *Murari*, *Ala Vaikunthapurramuloo*).
   - One-tap WhatsApp discussion with Ram regarding theme and festive vibe.

3. **Curated Event Gallery & Saved Inspiration**
   - Authentic photographs of real Addanki setups (Royal temple mandaps, teal velvet stages, floral arches, banquet hall decors).
   - Category filtering (Weddings, Engagements, Receptions, Birthdays, Corporate, Private).
   - Heart-save bookmarking to localStorage and swipe-enabled mobile lightbox.

4. **Venue Transformation Comparison Slider**
   - Interactive Before/After visual comparison demonstrating raw hall transformations into finished ceremonial stages.
   - Touch and drag responsive slider with dynamic viewport tracking.

5. **Date Availability Calendar**
   - Visual schedule indicator for booked and open dates.
   - Clear confirmation guidelines and instant date enquiry via WhatsApp.

6. **Host Testimonials with Telugu Expressions**
   - Real, casual feedback combining Telugu expressions with English summaries from families who hosted weddings, receptions, and traditional saree ceremonies.

7. **Mobile-First UX**
   - Sticky bottom action bar (`Call Ram` and `WhatsApp Ram`) with native safe-area inset support.
   - Smooth horizontal scrollable filters and responsive typography.

- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Playfair Display (editorial headings) & Inter (body)
- **Deployment:** Static SPA ready for Vercel, Netlify, Cloudflare Pages, or GitHub Pages.

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/srevents.git

# Navigate to project directory
cd srevents

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be available at `http://localhost:3000/`.

### Production Build

```bash
# Type check and build optimized static assets
npm run build

# Preview production build locally
npm run preview
```
